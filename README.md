# 🤖 Stock Bot - بوت تحليل المضاربة اليومية

سكربت Python يحلل أسهم S&P 500 الأكثر تداولاً كل **15 دقيقة** خلال ساعات السوق الأمريكي، ويرسل التوصيات (BUY / SELL) مباشرة لبوت تليجرام الخاص بك.

## 📊 كيف يعمل؟

البوت يجمع بين فلترين قويين قبل إصدار أي إشارة:

| المؤشر | الشرح |
|--------|--------|
| **VWAP** (Volume Weighted Average Price) | السعر المرجح بالحجم خلال اليوم — يكشف إن كان السعر فوق/تحت المتوسط الحقيقي |
| **Volume Spike** | يبحث عن قفزات في حجم التداول (≥1.8× متوسط آخر 20 شمعة) |
| **News Sentiment (VADER)** | يحلل آخر 12 ساعة من أخبار Yahoo Finance لكل سهم |

**منطق الإشارات:**
- 🟢 **BUY**: السعر اخترق VWAP صاعداً + قفزة حجم + أخبار إيجابية/محايدة
- 🔴 **SELL**: السعر كسر VWAP هابطاً + قفزة حجم + أخبار سلبية/محايدة
- ⚪ **HOLD**: إذا تعارضت الإشارة الفنية مع الأخبار

## 🚀 خطوات التشغيل

### 1. تثبيت المكتبات
```bash
pip install -r requirements.txt
```

### 2. إنشاء بوت تليجرام
- افتح تليجرام وابحث عن **@BotFather** وأرسل `/newbot`
- احفظ الـ **Token** الذي يعطيك إياه
- ابحث عن **@userinfobot** وأرسل `/start` لمعرفة **Chat ID** الخاص بك
- ⚠️ **مهم**: أرسل أي رسالة لبوتك أولاً ليستطيع التواصل معك

### 3. تعديل `config.py`
```python
TELEGRAM_BOT_TOKEN = "7891234567:AAH..."
TELEGRAM_CHAT_ID   = "123456789"
```

### 4. اختبر دورة واحدة (بدون إرسال)
```bash
python stock_bot.py --once --dry-run
```

### 5. شغّل البوت
```bash
python stock_bot.py              # تشغيل دائم
python stock_bot.py --once       # دورة واحدة فقط
```

## ⚙️ تخصيص الإعدادات

كل الإعدادات في `config.py`:

| الإعداد | الوصف | الافتراضي |
|--------|------|-----------|
| `TICKERS` | قائمة الأسهم المراقبة | 35 سهم S&P 500 |
| `VOLUME_SPIKE_MULT` | معامل قفزة الحجم | `1.8` |
| `MIN_PRICE` | أقل سعر مقبول | `$5` |
| `MIN_AVG_VOLUME` | أقل متوسط حجم | `500K` |
| `NEWS_LOOKBACK_HOURS` | فترة الأخبار | `12 ساعة` |
| `SENTIMENT_THRESHOLD` | عتبة المشاعر | `±0.20` |
| `RUN_EVERY_MINUTES` | الفاصل الزمني | `15` |
| `SEND_HOLD_SIGNALS` | إرسال إشارات HOLD؟ | `False` |

## ⚠️ تنبيه مهم

> **هذا السكربت أداة تحليلية فقط وليس نصيحة استثمارية.**
> المضاربة اليومية تحمل مخاطر عالية. لا تستخدم رأس مال لا تستطيع تحمل خسارته.
> اختبر السكربت بحساب وهمي (Paper Trading) لمدة كافية قبل المضاربة الفعلية.

## 💡 نصائح للاستخدام

1. **شغّله على VPS** (مثل DigitalOcean / AWS) ليعمل 24/7 دون انقطاع.
2. **اختر ساعات معينة** فقط من السوق إذا أردت تقليل الإشارات (مثلاً 10:00-15:00 ET).
3. **راجع `signals_history.csv`** أسبوعياً لتحليل أداء الإشارات.
4. **عدّل عتبات الفلتر** حسب أسلوبك (أقل = إشارات أكثر، أكثر = إشارات أدق).
